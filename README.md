# PDF Privacy Toolkit — Windows

**PDFを選択 → 3つの処理から選択 → 新しいファイルに出力**するシンプルなWindows向けツールです。

- 複数PDFの結合、ページ単位への分割、ページの順序・選択
- PDFの文書情報（Document Info）とXMPメタデータの除去
- 任意の出力パスワード（AES-256-R5）
- 既存出力の上書き防止、作成ファイルのページ数・メタデータ・暗号化状態の再確認

**機密情報の完全削除機能ではありません。** ページ本文、画像、注釈、フォーム、埋め込み添付などの機密情報の削除は証明できません。

`main` に存在するPDFフォーム一括入力の実装とWindows QA資産はそのまま保護しています。こちらはWindowsページ処理MVPからの独立した改良ブランチです。

検証・製品制限・販売に必要な残作業は [WINDOWS.md](WINDOWS.md) を参照してください。**Microsoft Store販売: HOLD（未承認）**。
